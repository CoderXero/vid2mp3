# Troubleshooting

Run `audioharbor doctor` first. A missing `ffmpeg` or `ffprobe` blocks conversion; a missing `yt-dlp` blocks extraction. The app never asks for a provider password. Use a supported browser-session import or Netscape cookie file when the provider requires an authenticated session.

Provider authentication, challenges, regional restrictions, DRM, and rate limits are distinct conditions. A successful sign-in does not grant download rights.
